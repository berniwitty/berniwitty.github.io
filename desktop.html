层级版本记忆的长程稳定Hierarchical versioned memory for long-horizon stability针对 MemAgent 记忆在低频场景偏好被截断遗忘的问题，构建“原始日志—偏好条目—主题组”层级记忆，由 LLM 解析带原文证据的增删改操作，写入按类别版本化入库并自动失效旧值。后半程成功率仅下降 0.7%，较 MemAgent 记忆（15.9%）显著改善，与全量上下文持平。because MemAgent's memory truncates and forgets preferences in low-frequency scenarios, a raw log → preference entry → topic group hierarchical memory was built: an LLM parses add / delete / update operations with source evidence, and writes are versioned per category with old values expiring automatically.
